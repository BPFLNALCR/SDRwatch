      Tuning controls
      

        
Common RF settings. The default preset favors first-light RTL-SDR v4 signal cards through the web workflow.


        

          
          

            GUI Tuning Preset
            

              

                
                
              

              

                

                  First-light RTL-SDR v4: fixed 30 dB gain, fast non-overlapping 2.4 MS/s step, FFT 8192/avg 8, and relaxed 1/1 promotion so initial cards can appear.
                

              

            

          


          
          

            SDR Configuration
            

              

                
                
              

              

                
                
                
                
Fixed gain improves baseline repeatability; start near 30 dB for RTL-SDR v4 and reduce it if strong signals overload.

              

            

          


          
          

            FFT & Averaging
            

              

                
                
                
Lower FFT scans faster; higher FFT improves frequency resolution and signal characterization but slows wide sweeps.

              

              

                
                
                
More averaging smooths noise and steadies peaks, but each sweep updates more slowly.

              

            

          


          
          

            Detection Thresholds
            

              

                

                  
                  8
                

                
                
Detection threshold above the learned noise floor.

              

              

                

                  
                  1
                

                
                
Below-threshold bins allowed inside one detection.

              

              

                

                  
                  2
                

                
                
Minimum contiguous bins before a detection is reported.

              

            

          


          
          

            CFAR (Constant False Alarm Rate)
            

              

                
                
                
Controls how local noise is estimated around each bin.

              

              

                

                  
                  0.75
                

                
                
Order-statistic percentile used by OS-CFAR.

              

              

                
                

                  
                  8
                

                
                
Optional CFAR threshold scaling override.
